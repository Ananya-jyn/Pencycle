# Pencycle – Smart Pen Waste Management System

## Project Description
Pencycle is a sustainable waste management initiative designed to be implemented in schools and colleges to encourage the proper disposal and recycling of used pens. The system provides students with coded pens and dedicated collection bins where they can dispose of their used pens after use.

Each time a student disposes of a pen, they earn reward points that can be redeemed for concessions in college canteens and other participating facilities. By combining waste collection with a reward-based system, Pencycle aims to motivate students to adopt eco-friendly habits and actively participate in campus waste management.

## Key Features
- Coded pens for tracking disposal.
- Dedicated bins for collecting used pens.
- Reward points for every pen disposed of.
- Points redeemable for canteen concessions and other benefits.
- Promotes responsible waste disposal and recycling.

## Objective
To reduce pen waste in educational institutions by encouraging students to dispose of used pens responsibly through an incentive-based waste management system.

## Impact
Pencycle aims to create cleaner campuses, reduce improper pen disposal, promote recycling awareness, and develop sustainable habits among students.
